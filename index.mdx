Aura is a prediction market on Alephium. You trade shares in whether something
will happen, and the winning side pays out $1 per share. Prices are probabilities,
so a market at $0.64 is the crowd saying 64%.

Everything runs on-chain: the order books, the collateral, the resolution, and the
payouts. Aura never holds your keys.

## Build on Aura

Market data is public and needs no key. Trading is non-custodial: the API builds
unsigned transactions and your wallet signs them.

<CodeGroup>
```bash cURL
curl -s "https://api.aura.markets/v1/markets?limit=5&status=open"
```

```javascript JavaScript
const { markets } = await fetch(
  'https://api.aura.markets/v1/markets?limit=5&status=open'
).then((r) => r.json())

for (const m of markets) console.log(m.question, m.bestBidYes)
```

```python Python
import requests

res = requests.get(
    "https://api.aura.markets/v1/markets",
    params={"limit": 5, "status": "open"},
)

for m in res.json()["markets"]:
    print(m["question"], m["bestBidYes"])
```
