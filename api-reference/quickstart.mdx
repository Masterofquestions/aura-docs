Public market data requires no credential. Start by reading the deployment
configuration rather than copying network constants from an example.

## 1. Read canonical configuration

```bash
curl -s https://api.aura.markets/v1/protocol/config
```

Important fields include `network`, `contracts`, `collateral`, `trading`,
`fees`, `marketCreation` and `realtime`. Exact quantities and durations are
strings with their units in the field name. `realtime.sources` identifies the
active `main`/`sequencer`/`wallet` cursor components; its retention fields are
minimum replay guarantees, not a current stream cursor.

## 2. List open markets

<CodeGroup>
```bash cURL
curl -s "https://api.aura.markets/v1/markets?limit=5&status=open&sort=volume&order=desc"
```

```ts TypeScript
import { createAuraClient } from '@aura/builder-sdk'

const aura = createAuraClient({ baseUrl: 'https://api.aura.markets' })
const page = await aura.markets.list({
  limit: 5,
  status: 'open',
  sort: 'volume',
  order: 'desc',
})

for (const market of page.markets) {
  console.log(market.marketAddress, market.question, market.lifecycle.tradingStatus)
}
```

```python Python
import requests

page = requests.get(
    "https://api.aura.markets/v1/markets",
    params={"limit": 5, "status": "open", "sort": "volume", "order": "desc"},
).json()
```
</CodeGroup>

Follow `pagination.nextCursor`; do not synthesize an offset for fast-changing
trading data.

## 3. Read a versioned book snapshot

The realtime snapshot endpoint uses the clearinghouse market ID (64 lowercase
hex characters):

```bash
curl -s "https://api.aura.markets/v1/realtime/book/${MARKET_ID}/snapshot"
```

Keep `bookVersion` and `streamCursor` with the levels. Then subscribe to
`market:${MARKET_ID}:book` after that cursor. This snapshot-then-replay pattern
closes the race between the REST request and the stream connection.

## 4. Request a point-in-time quote

Quotes use the same matcher, fee and rounding logic as order execution.

```ts
import { baseUnits, priceTick } from '@aura/builder-sdk'

const quote = await aura.markets.quote(marketAddress, {
  outcome: 'yes',
  side: 'buy',
  orderType: 'gtc_limit',
  quantityBaseUnits: baseUnits('1000000000000000000'),
  limitPriceTick: priceTick(600),
})

console.log(quote.bookVersion, quote.estimate.requiredCollateralBaseUnits)
```

A quote is never a guaranteed fill. Inspect `expiresAt`, `bookVersion`,
`unfilledQuantityBaseUnits` and every warning before presenting it.

## 5. Read honest history

```ts
const candles = await aura.markets.candles(marketAddress, {
  interval: '5m',
  from: new Date(Date.now() - 86_400_000).toISOString(),
  to: new Date().toISOString(),
})

const retainedBook = await aura.markets.microstructure(marketAddress)
```

Candles contain settled Clearinghouse fills only. Microstructure is sampled
retained state; missing intervals remain gaps and are never backfilled from the
current book.
